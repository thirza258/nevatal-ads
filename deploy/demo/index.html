AdControl self-hosted demo

A normal web page with centrally managed ads.

This static host page loads the real AdControl browser SDK. The page still works if the ad service is unavailable; the ad containers simply stay empty.

Demo status

Reading the demo configuration…

Add this demo's origin () to the website's allowed domains in AdControl before expecting delivery or click tracking to work.

The SDK never receives the admin password or secret key. It only gets the public site key and signed, short-lived click URLs.

Integration surface

Ad placements

Each element below is a plain div with a data-adcontrol-placement attribute. No host-page JavaScript is needed to render them.

Local publishing, central control

Editors keep writing and shipping their sites normally. Ad destinations, schedules, creatives, and placement assignments are changed in AdControl and picked up by the SDK without redeploying this page.

Impressions are counted only after at least half of an ad has been visible for one second. Clicks go through a signed redirect that re-validates the campaign and the page origin on the server.
